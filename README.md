# Catacombs

A roguelike cat-based on-chain adventure game. Your cat goes on journeys through procedurally generated dungeons — their travels and accumulated items are recorded on-chain.

## Reference Projects

See `reference/` for three Starknet game projects used as architectural references:

- **[starter](reference/starter)** — Simple treasure hunt grid game (Dojo ECS, best starting point)
- **[number-guess](reference/number-guess)** — Number guessing game (raw Starknet + Apibara indexing)
- **[nums](reference/nums)** — Complex number puzzle (production-grade Dojo game)

See [reference/README.md](reference/README.md) for detailed comparison and patterns.
